Plateforme web Montessori pour enfants : jeux interactifs couvrant les compétences des cycles d'apprentissage (éveil, maternelle, primaire).

**Why:** Rendre l'apprentissage Montessori accessible et engageant via le numérique.

**How to apply:** Prioriser l'expérience enfant (UX simple, colorée, ludique), penser aux cycles d'âge lors des choix de contenu et de difficulté. Backend Python, frontend JS/TS.
